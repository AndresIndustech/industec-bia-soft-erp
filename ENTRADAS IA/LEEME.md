# ENTRADAS IA — dónde dejar material para el sistema

Esta carpeta está **sincronizada con Google Drive**: lo que dejes aquí desde cualquier equipo llega a la estación de IA. Es el buzón de entrada del sistema.

**Lo que dejes aquí no se modifica ni se borra.** El sistema lo lee, lo copia a su repositorio de trabajo y produce sus resultados en `SALIDAS IA`. Tu original se queda como está.

## Dónde va cada cosa

| Carpeta | Qué dejar |
|---|---|
| **DATOS EMPRESA** | Maestros y catálogos: locales, empleados, listas de equipos |
| **MANTENIMIENTO** | Planes de trabajo, seguimientos y material de la operación |
| **REPORTES** | Reportes y exports de SAP (por ejemplo el de KPIs) |
| **PRESENTACIONES** | Material de presentaciones |
| **SISTEMA OTS INDUSTEC** | Todo lo relativo al sistema de órdenes de trabajo |
| **PROVEEDOR INDUSTECH INFO** | Documentos del servicio: cotización, acuerdos |

## Para que el sistema lo aproveche bien

- **Excel mejor que PDF** cuando exista la opción: de un Excel se leen los datos directamente; de un PDF hay que interpretarlos.
- **No hace falta que renombres nada.** El sistema resuelve nombres inconsistentes; para eso está el saneamiento.
- **Si un archivo reemplaza a otro, deja los dos.** El sistema compara por contenido y decide; borrar el viejo le quita evidencia.
- **Avisa qué dejaste** si es algo que esperas que se procese pronto. La carpeta se revisa, pero un aviso evita que quede esperando.

## Lo que el sistema te devuelve

En `SALIDAS IA` (ver su propio `LEEME.md`). Lo que espera decisión tuya está en `SALIDAS IA\CALIDAD`, con una columna **VEREDICTO ADMIN** donde lo que marques se respeta en las corridas siguientes.
